## 2. 数据体检结果（2026-09-11 实测，已全部修复）

原始数据 6,719 图 / 18,768 实例，格式是标准 YOLO（`class cx cy w h`），**图标签一一对应、无缺标签、无孤儿标签、无空标签、无坐标越界**。但查出 4 个问题：

| # | 问题 | 实测 | 处理 |
|---|---|---|---|
| 1 | **跨 split 图片重复（数据泄漏）** | **280 组** MD5 完全相同：`test/A (218).jpg` = `train/F (1303).jpg` 等 | ✅ 从 train 剔除 **281 张**，复检跨 split 重复 = **0** |
| 2 | **类别极端不平衡** | 最多 `baitaishe` 5167，最少 `shenqutu` **2**（差 2500 倍） | ✅ 剔掉实例 <250 的类（`--min-instances 250`） |
| 3 | **实际 21 个 id，含未定义 id 与空类** | id 出现 `0~21`，其中 `20`(2)、`21`(7) 论文未定义；`18`(xinfeitu) **零实例** | ✅ 8 个类整体剔除，类别重编号为 0~13 |
| 4 | **没有 classes.txt** | 6719 个 .txt 全是标签，无类别名文件 | ✅ 内置论文顺序的 id→英文名映射，生成新 `classes.txt` |

其他观察（未处理，但要知道）：

- 图片尺寸跨度极大：**87×67 到 3648×2736**，中位数仅 580×640 → 小图放大到 640 会糊
- 文件名带空格括号（`A (1000).jpg`），前缀 `A`/`F`/`tongue` 混合 → 多批次来源，这也是重复图的来源
- 极小目标：`hongdianshe`（红点舌）框只有 **4×9 像素**，却是实例第二多的类（3638 个）→ 会拉低整体 mAP
- train 内部仍有 **191 组**内容重复（不影响测试指标，未处理）

**结论层**（规则推导，可解释、可审计）：

| 用户侧维度 | 规则 | 当前状态 |

## 12. 常见问题

### 12.1 上传失败（`Connection closed by ... port ...`）

**症状**：scp/ssh 报 `Connection closed by <IP> port <端口>`，连密码提示都没出现。

**含义**：TCP 连通了，但服务器立刻断开 → 说明**你连的不是自己的实例**，或实例没就绪。

| 排查项 | 怎么确认 |
|---|---|
| ① 端口/域名是不是示例值 | 必须从实例卡片「登录指令」**复制**，`12345`/`connect.autodl.com` 只是我文档里的占位符 |
| ② 实例是否「运行中」 | 控制台看状态；「开机中」时连不上 |
| ③ 密码对不对 | 用实例卡片的「密码」按钮，不是 AutoDL 账号密码 |
| ④ 实例是否重建过 | 重建后端口会变，要重新复制 |
| ⑤ 先用 `ssh` 验证再传文件 | `ssh -p <端口> root@<域名>` 能进得去，再执行 scp |

**其他备选上传方式**：

- 实例页面 →「JupyterLab」→ 左侧文件树进 `/root/autodl-tmp` → 直接把 zip 拖进去（不需要 SSH）
- FileZilla / WinSCP 图形化 SFTP（协议选 SFTP，填同样的主机/端口/密码）
- `scp` 加 `-O` 参数强制旧协议（某些环境新 SCP 协议的 SFTP 子系统握手会失败）

### 12.2 其他问题

| 现象 | 原因 | 解决 |
|---|---|---|
| `$'\r': command not found` | Windows 上传的 .sh 带 CRLF | `sed -i 's/\r$//' scripts/train_tongue_autodl.sh` |
| `FileNotFoundError: ... images not found` | ultralytics 全局 `datasets_dir` 劫持相对路径 | 脚本已**强制重写**绝对路径 yaml，无需手动处理 |
| 训练中途 SSH 断，任务没了 | 没开 tmux | 重进 `tmux new -s t` 重跑 |
| 系统盘爆满 | 输出写到 `/root/runs` | 脚本已把 `project` 指向 `/root/autodl-tmp/runs` |
| `CUDA out of memory` | batch/imgsz 太大 | `BATCH=16` 或 `IMGSZ=512` |
| 某类 mAP50 很低 | 该类样本少或目标极小（如红点舌） | 看逐类指标；必要时提高 `--min-instances` 再裁 |
| 数据盘不够 | 中间产物堆积 | 清理 `runs/*/weights/*.pt` 旧文件 |
| 本地 .ps1 跑不起来/乱码 | 无 BOM 的 UTF-8 被 PowerShell 5.1 按 GBK 读 | 上传助手已带 BOM；自己写脚本记得存 UTF-8 with BOM |
| 本地执行 .ps1 被拦 | 执行策略限制 | 用 `powershell -ExecutionPolicy Bypass -File xxx.ps1` |
