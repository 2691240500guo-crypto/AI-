## 2. 测试准备

1. 用户端登录 `user / user123`，管理端登录 `admin / admin123`。
2. 用户端进入“隐私与数据”，同意健康数据使用说明。除“健康检查、登录、部分只读页面”外，健康数据接口默认要求同意。
3. 知识库测试准备一个小文本文件，例如 `docs/test-data/营养测试知识.txt`，内容至少包含：高蛋白饮食、糖尿病饮食、睡眠建议等可检索短句。
4. 舌象测试图片可使用：`backend/data/tongue_dataset/test/images/` 中任意图片；该目录有 50 张测试图片。
5. 每条用例执行后，在“结果”列填写：`通过 / 失败 / 阻塞`，并记录会话 ID、记录 ID 或截图路径。
