本目录存放舌象模块的两代权重。**线上使用的是 v2（14 类多特征检测）**。

| 文件 | 用途 | 状态 |
|---|---|---|
| `yolov8n-tcm-tongue.pt` | **v2 · 14 类舌象多特征检测**（TCM-Tongue 中医师标注数据集） | ✅ 线上生效（`.env` → `TONGUE_YOLO_MODEL`） |
| `yolov8n-tcm-tongue-v1.pt` | v2 之前的一版 14 类实验权重（默认增强参数） | 归档，仅用于对比 |

## v2 · 舌象多特征检测（当前线上模型）

- 架构：Ultralytics YOLOv8n，单次前向输出 **14 类**特征，**一张图可同时命中多个**（实测平均 2.1 个）
- 权重来源：`yolov8n.pt`（Ultralytics 官方 COCO 预训练）迁移学习
- 训练日期：2026-09-11（AutoDL · RTX 3080Ti）
- 数据：`data/tcm_tongue`（源自公开学术数据集 TCM-Tongue，**持证中医师标注**；本地做过跨 split 去重与稀有类裁剪）
- 训练命令（云端一键脚本）：
  ```bash
  bash scripts/train_tongue_autodl.sh
  # 等价核心参数：--epochs 150 --imgsz 640 --batch 32
  #   --mosaic 0 --erasing 0 --scale 0.25 --translate 0.05 --fliplr 0 --cls 1.0 --hsv-s 0.3 --hsv-v 0.3
  ```
- 实际训练：**127 epoch 触发早停**（best 出现在第 27 轮，patience=100）

### 类别与实测可靠性

指标口径：**图级多标签检出率**（test 552 张，conf≥0.25）——
比较「模型检出的类别集合」与「标注类别集合」，而非 mAP。
理由：本模块的用途是判断"舌象上出现了哪些特征"，框的精确位置不影响结论。

复现命令：`./venv/Scripts/python.exe scripts/evaluate_tongue_features.py --conf 0.25`

### 已知能力边界（必须如实对外表述）

1. **暗红（紫舌）能力缺失**：全库仅 244 个实例（test 0/18），检测图级召回 0。
   **归因（已实测排除其他解释）**：主因是**与红舌的类别竞争 + 视觉可分性低**，样本量只是放大因素——
   ① 样本量非决定因素：`shoushe` 仅 217 张 train 图却拿到 0.767 召回，`zishe` 200 张得 0；
   `hongdianshe` 1034 张却只有 0.050；
   ② zishe 与 hongshe 标注互斥（同图仅 3.7%），而 hongshe 图数是其 6 倍 → 18 张紫舌图中 11 张被预测成红舌；
   ③ 整图颜色/亮度规则法（train+val 标定 → test 评估）准确率仅 0.67~0.69、紫舌精确率约 0.50，说明两类分布大面积重叠；
   ④ 阈值无法补救：降到 0.05 时召回 0.33 但误报 37 张、精确率仅 0.14。
   "白苔覆盖遮挡舌色"这一假说**已排除**（红舌的白苔共现率 59.3% 与紫舌 58.0% 相同）。
   → **推荐路径是改任务形式**（舌体 ROI + 舌色 3 类分类头），而不是单纯补样本。
2. **苔的厚薄无法判断**：数据集没有「厚苔」标注；实测苔框面积占整图比例全部落在 0.71~1.00（中位 0.84），
   因为苔类标注是"整舌级"大框，**面积与厚薄无关**。因此产品只输出「覆盖范围」，不输出厚薄。
   要做真厚薄需 TongueDx 数据集的 `FurThick` 字段（需申请）。
3. **极小目标不可用**：红点舌标注框仅约 4×9 像素，640 输入下基本不可见。
4. **测试集可能含增强图**：部分图片名为 `randomRotation*` / 同一批次重命名，指标不代表跨设备泛化能力。

### 与 v1（单类定位）的关系

v1 只做一件事——把舌头框出来，其 mAP50 0.995 属于**简单任务**（单类、大目标、同源图片）。
v2 换成 14 类多标签检测后整体 mAP 下降到 0.385 是**任务难度变了**，不是模型退化。
若只需要舌体 ROI，继续用 `yolov8n-tongue.pt.bak`。

## 安全与合规

- 本模块只做「舌象特征观察」，**不输出诊断、证型或处方**；API 响应固定携带免责声明。
- 原图以客户端加密形式存入 MinIO 私有桶，回显走带 Token 的网关接口（非本人 404）。
- **用户真实舌象照片严禁上传到第三方云或混入公开训练集**（隐私红线）。
- 面向用户的表述只能引用**图级指标**，且必须同时说明上面的「已知能力边界」。
